# AWS Cloud Project

This repository contains my work for the Solution Architecture Design and Cloud Deployment project.

The project is completed as part of the AWS Solution Architect training. AWS is used as the cloud service provider and Terraform is used for Infrastructure as Code (IaC).

## Project Structure

The project is divided into Baseline and Target level tasks.

### Baseline Tasks
```bash
Baseline01 - Version Control
Baseline02 - Project Management
Baseline03 - Complex System Selection
Baseline04 - Networking
Baseline05 - Firewall
Baseline06 - Virtual Machine
...
```

### Target Tasks

Target level tasks will extend the baseline infrastructure and are documented separately.

## Technologies
```bash
AWS
Terraform
Git
GitHub
AWS CloudShell
```

## Complex System

CTFd was selected as the complex system for the project.

The final infrastructure will be developed step by step during the project.

## Documentation

Each baseline task contains its own documentation, Terraform configuration when required, and screenshots used to verify the implementation.
